# Best Buy Product Service

This service provides the product catalog API for the Best Buy Cloud-Native Application.

## Responsibilities
- Return a list of products
- Return a single product by ID
- Add new products
- Update existing products
- Support product management for the store-admin app
- Provide product data to the store-front app

## Tech Stack
- Rust
- Docker

## Related Services
- store-front
- store-admin
- order-service
- makeline-service

## Notes
This service is currently based on the Lab 8 starter and is being adapted for the Best Buy final project.
